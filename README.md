# Древо пророков — PWA для GitHub Pages и PWABuilder

Готовый статический сайт (без сборки). Содержимое папки — это и есть сайт.

## 1. Публикация на GitHub Pages

1. Создайте на GitHub **публичный** репозиторий.
   - Хотите, чтобы будущее Android-приложение открывалось **без адресной строки**, назовите его строго `ВАШ_ЛОГИН.github.io` (см. шаг 4).
   - Подойдёт и любое другое имя, например `prophet-tree`; тогда адрес будет `https://ВАШ_ЛОГИН.github.io/prophet-tree/`.
2. Загрузите **всё содержимое этой папки** в корень репозитория: `index.html`, `manifest.webmanifest`, `sw.js`, папки `icons/` и `vendor/`, а также файл `.nojekyll`.
   В веб-интерфейсе: *Add file → Upload files*, перетащите файлы и папки. Если файл `.nojekyll` не виден в проводнике, создайте его на GitHub: *Add file → Create new file*, имя `.nojekyll`, пустое содержимое.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.*
4. Через 1–2 минуты сайт откроется по адресу из раздела Pages.

Проверка: откройте адрес на телефоне в Chrome. Должно появиться «Установить приложение» (в приложении есть и своя кнопка «Установить»). Для проверки PWA можно запустить Lighthouse в Chrome DevTools.

## 2. APK через PWABuilder

1. Откройте https://www.pwabuilder.com, вставьте адрес сайта и нажмите *Start*.
2. Дождитесь отчёта: манифест, service worker и иконки должны быть без красных ошибок.
3. *Package for stores → Android*. Укажите:
   - **Package ID** — например `io.github.ВАШ_ЛОГИН.prophettree` (потом изменить нельзя, если будете публиковать в Google Play);
   - название, версию (`1.0.0`, код версии `1`);
   - подпись: **New** (PWABuilder создаст ключ). *Обязательно скачайте и сохраните файл ключа и пароли* — без них нельзя выпускать обновления.
4. Скачайте архив: в нём `.apk` для установки на телефон, `.aab` для Google Play и подсказка с файлом `assetlinks.json`.
5. APK на телефоне: разрешите установку из неизвестных источников и откройте файл.

## 3. Чтобы приложение открывалось на весь экран (без адресной строки)

Android проверяет, что сайт «принадлежит» приложению, через файл
`https://ВАШ_ЛОГИН.github.io/.well-known/assetlinks.json`
(PWABuilder даёт его готовое содержимое с отпечатком SHA-256 вашего ключа).

- Файл должен лежать в **корне домена**. Поэтому нужен репозиторий `ВАШ_ЛОГИН.github.io`: положите в него папку `.well-known/` с `assetlinks.json` (файл `.nojekyll` обязателен).
- Если сайт лежит в проектном репозитории (`.../prophet-tree/`), файл всё равно нужно поместить в репозиторий `ВАШ_ЛОГИН.github.io`; без него приложение откроется с адресной строкой Chrome, но будет работать.
- Если публикуете в Google Play, отпечаток подписи Google может отличаться — добавьте и его в `assetlinks.json`.

## 4. Офлайн и обновления

- Первое открытие нужно онлайн. После этого `sw.js` кэширует приложение и библиотеку d3; дальше оно запускается без сети.
- Для работы офлайн с самого первого запуска скачайте `d3.min.js` (v7.8.5) в папку `vendor/` (ссылка в `vendor/README.txt`).
- Обновили сайт? В `sw.js` увеличьте номер версии в `const V="ptree-v1"` (например, `v2`). APK пересобирать не нужно: оно загружает сайт.
- Кнопки «Скачать» (SVG, PNG, JSON, CSV, досье) работают в браузере и в приложении как обычные загрузки.

## 5. Важно

- Данные в приложении демонстрационные: ссылки на классические труды (Ибн Са‘д, Ибн Хаджар и др.) ещё не сверены с изданиями, и это указано в карточках.
- GitHub Pages публичен: любой, кто знает адрес, увидит сайт и данные.
